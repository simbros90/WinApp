# PC Info App - Windows Desktop Application

Приложение для отображения всех характеристик компьютера в едином окне.

## Требования

- Python 3.7+
- Windows (для полной функциональности)

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск приложения

```bash
python pc_info_app.py
```

## Функции

Приложение отображает следующую информацию в виде вкладок:

1. **Система** - ОС, архитектура, имя компьютера, время загрузки и работы
2. **Процессор** - модель, частота, количество ядер, загрузка CPU
3. **Оперативная память** - общий объем, доступная память, использование, swap
4. **Диски** - разделы дисков, свободное место, статистика чтения/записи
5. **Сеть** - сетевые интерфейсы, IP-адреса, статистика трафика
6. **Видеокарта** - информация о GPU и памяти видеокарты

## Возможности

- **Обновление** - кнопка для обновления всей информации
- **Копировать всё** - копирование всей информации в буфер обмена
- **Статус бар** - отображение времени последнего обновления

## Примечания

- Приложение использует tkinter для графического интерфейса (входит в стандартную библиотеку Python)
- Для получения информации о железе используются библиотеки psutil и py-cpuinfo
- На Windows приложение получает дополнительную информацию через WMIC и PowerShell
